# 🎮 Loja de Jogos 

Projeto acadêmico de Banco de Dados desenvolvido para representar o funcionamento de uma loja virtual de jogos digitais para PC, Xbox e PlayStation.

## 📌 Sobre o projeto

O projeto permite organizar informações sobre clientes, pedidos, pagamentos, jogos, plataformas e categorias, simulando as principais operações de uma loja de jogos digitais.

## 🗄️ Estrutura do banco de dados

O banco de dados é composto por 9 tabelas:

- **CLIENTE:** armazena os dados dos clientes.
- **PEDIDO:** registra os pedidos realizados.
- **PAGAMENTO:** armazena as informações dos pagamentos.
- **ITEM_PEDIDO:** registra os jogos presentes em cada pedido.
- **JOGO:** armazena os dados dos jogos.
- **JOGO_PLATAFORMA:** relaciona jogos às plataformas e seus preços.
- **PLATAFORMA:** registra as plataformas disponíveis.
- **CATEGORIA:** armazena as categorias dos jogos.
- **JOGO_CATEGORIA:** relaciona jogos às suas categorias.
